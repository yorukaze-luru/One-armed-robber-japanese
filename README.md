# One-armed robber 非公式日本語化パッチ (Unofficial Japanese Patch)

Steamにて無料配信中の片腕強盗FPS**『One-armed robber』**の最新バージョンを完全日本語化する非公式パッチです。  
ゲーム内のUI、メニュー、設定項目、キーバインド設定、HUD、ダイアログ、新マップ「データセンター」を含む全ステージ名・目標指示、セットアップ、クレート・武器スキン＆チャーム、全アイテム名・注視名、スキル効果説明など、プレイに必要なあらゆるテキストを自然な日本語にローカライズします。

---

## 🌟 特徴 (v2.0.1)

- **📂 ゲームフォルダに入れるだけで簡単導入**  
  解凍した `OAR` フォルダをゲームフォルダに入れるだけで、即座に日本語化が適用されます。余計なバッチやスクリプトは一切含みません。
- **🏢 最新アップデート「データセンター (Data Center)」完全対応**  
  最新ゲームデータ（`default`）をベースに再構築し、新ステージ「データセンター」のマップ選択表示、ステージ説明、ミッション目標指示、新戦利品（AI学習データ・RAMメモリ）に完全対応しています。
- **🎯 アイテム名・オブジェクト注視名・全12ステージ・セットアップ・スキンの完全日本語化**  
  強盗ツール、貴重品、武器、アタッチメント、防具、マスク、衣装、エモート、クレート＆武器スキン/チャーム（DataTable）、全スキルのTier別効果詳細、マップ内ギミック（配電盤、ドア、掌紋スキャナー、遠心分離機など）の注視名を網羅的に日本語化しています。
- **🚀 動的テキスト（ゲーム開始・準備完了・装備中など）の完全日本語表示＆クラッシュ防止**  
  Unreal Engine 4.27の `.locres` 文字列ハッシュ（`StrCrc32`）を正規化し、`UFunction` バイトコードを一切破壊せずに全26箇所の動的テキスト（「ゲーム開始」「準備完了」「準備解除」「ゲームを探す」「ロビーを抜ける」「購入済！」「装備中」など）を100%安全に日本語表示します。
- **🎮 タイトルロゴは英語を維持**  
  メインメニューのタイトルロゴは英語（`ONE-ARMED ROBBER`）のまま表示され、スタイリッシュな雰囲気を保ちます。

## 🛠️ インストール手順（手動導入）

ファイルをコピーするだけで簡単に導入できます。

1. ダウンロードした `One-armed_robber_Japanese_Patch.zip` を解凍します。
2. 解凍したフォルダ内にある **`OAR`** フォルダを、ゲームのインストールフォルダ（`OAR.exe` がある場所）にそのままドラッグ＆ドロップ（上書きコピー）してください。
3. 通常通りSteamからゲームを起動すれば、日本語化が完了しています！

> [!TIP]
> **Steam版の一般的なインストール先フォルダ：**  
> `C:\Program Files (x86)\Steam\steamapps\common\One-armed robber\`  
> （Steamライブラリでゲームを右クリック ➔「管理」➔「ローカルファイルを閲覧」で一発で開けます）

---

## 🗑️ アンインストール手順（元の英語に戻す場合）

ゲームフォルダ内の以下のファイルを削除するだけで、いつでも元の英語に戻せます：  
`OAR\Content\Paks\OAR-WindowsNoEditor_Japanese_P.pak`

## ❓ よくある質問 (FAQ)

<details>
<summary><b>Q. ゲームのアップデートがあった場合はどうなりますか？</b></summary>
パッチは独立したPakファイル（<code>_P.pak</code>）として動作します。v2.0.1では最新の「データセンター」アップデートに完全対応しています。
</details>

<details>
<summary><b>Q. オンラインマルチプレイ（Co-op）でも使えますか？</b></summary>
はい。UIの表示テキストおよびフォントのみを変更するクライアントサイドModのため、オンラインマルチプレイでも問題なく動作します。
</details>
