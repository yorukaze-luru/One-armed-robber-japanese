======================================================================
  One-armed robber 非公式日本語化パッチ v2.0.1 (手動導入版)
======================================================================

本パッチは、フォルダ内の「OAR」フォルダをゲームのインストール先にコピーするだけで
誰でも簡単に日本語化できるパッチです。

----------------------------------------------------------------------
■ 導入方法（かんたん 3ステップ）
----------------------------------------------------------------------

1. Steamライブラリを開き、「One-armed robber」を右クリックします。
   ➔「管理」➔「ローカルファイルを閲覧」をクリックしてゲームフォルダを開きます。
   （※「OAR.exe」や「OAR」フォルダがあるフォルダが開きます）

2. 本フォルダ内の「OAR」フォルダを、
   そのまま上記で開いたゲームフォルダへドラッグ＆ドロップ（上書きコピー）してください。
   ※既存のゲームデータが消えることはありません。「Paks」フォルダ内にパッチファイルが安全に追加されます。

3. ゲームを起動すると、UI・設定・チュートリアル・全ステージ・アイテム・目標指示が日本語で表示されます！


----------------------------------------------------------------------
■ 元の英語に戻す方法（アンインストール）
----------------------------------------------------------------------
いつでもパッチファイルを1つ削除するだけで元の英語に戻せます。

ゲームフォルダ内の以下のファイルを削除してください：
  OAR \ Content \ Paks \ OAR-WindowsNoEditor_Japanese_P.pak
