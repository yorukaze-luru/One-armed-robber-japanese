======================================================================
  One-armed robber (ワンアームド・ロバー) 日本語化パッチ 配布パッケージ
======================================================================

Steam無料ゲーム『One-armed robber』のUIテキストおよびメッセージを日本語化するパッチです。

----------------------------------------------------------------------
■ 導入方法（どちらかお好きな方法で導入できます）
----------------------------------------------------------------------

【方法1：自動インストール（推奨・かんたん）】
  1. 本フォルダ内にある「[自動インストール] 日本語化パッチ適用.bat」を
     ダブルクリックして実行するだけです。
  2. ゲームを通常通り起動すると日本語化されています。

【方法2：手動インストール（フォルダをコピーするだけ）】
  1. 本フォルダ内にある「OAR」フォルダを、
     ゲームのインストールフォルダ（OAR.exe があるフォルダ）に
     そのままドラッグ＆ドロップ（上書きコピー）してください。
     ※元のファイルは上書き・変更されず、「OAR\Content\Paks」の中に
       パッチファイル（OAR-WindowsNoEditor_Japanese_P.pak）が追加されるだけです。
  2. ゲームを通常通り起動してください。

※Steam版の一般的なインストール先：
  C:\Program Files (x86)\Steam\steamapps\common\One-armed robber\

----------------------------------------------------------------------
■ アンインストール方法（元の英語に戻したい場合）
----------------------------------------------------------------------
- 自動：「[自動アンインストール] パッチ削除.bat」を実行してください。
- 手動：ゲームフォルダ内の「OAR\Content\Paks\OAR-WindowsNoEditor_Japanese_P.pak」
        を削除するだけで、即座に完全な元の英語状態に戻ります。
